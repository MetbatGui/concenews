# 프론트엔드 설계 지침

> 프론트엔드 작업 시에만 참조. 라우팅: [AGENTS.md § 언제 무엇을 볼까](../AGENTS.md)

## 전제

사용자는 프론트엔드 미경험이다. 따라서 에이전트가 설계 판단을 주도하고, 판단 근거를 설명한다.

## 작업 원칙

- **프론트엔드 엔지니어 입장에서 생각한다.** 백엔드 관점의 편의로 구조를 결정하지 않는다.
- 백엔드 도메인 구조를 프론트 아키텍처로 매핑한다.
- Vue 컴포넌트 설계와 상태 관리(Pinia) 구조를 제안한다.
- 사용자에게 "왜 이렇게 설계하는가"를 설명한다.
