# 제품 비전

> 이 문서는 장기적인 지향점이다. 구현 범위와 우선순위는 각 Slice의 Spec과 Plan이 결정하며, 학습·데이터 접근성·사용자 피드백에 따라 언제든 갱신한다.

## 북극성

Concenews는 거시경제 뉴스, 예측시장 가격, 참여자 자금 흐름을 사람이 이해할 수 있는 **경제 이슈**에 연결해, 지금 무엇이 변하고 있는지와 그 근거를 빠르게 보여주는 매크로 인텔리전스 플랫폼을 지향한다.

서비스는 미래를 확정적으로 예측하거나 투자 조언을 제공하지 않는다. 뉴스·시장·행동 데이터에서 관찰되는 변화와 불확실성을 근거와 함께 제시한다.

## 사용자가 답을 얻는 질문

- 지금 중요해지고 있는 거시경제 이슈는 무엇인가?
- 예측시장은 어느 방향으로, 얼마나 빠르게 움직이고 있는가?
- 뉴스·경제지표·시장 움직임은 어떤 이슈로 연결되는가?
- 관찰 가능한 참여자 행동 중 추가 검토가 필요한 집중·선행 신호가 있는가?

## 제품 원칙

1. **이슈 중심**: 키워드 나열보다 이해 가능한 경제 이슈를 중심으로 데이터를 연결한다.
2. **변화 중심**: 절대값보다 뉴스량, 확률, 거래량, 유동성, 자금 흐름의 시간별 변화를 본다.
3. **근거 제시**: 모든 신호는 연결된 뉴스·시장 데이터·계산 근거로 추적할 수 있어야 한다.
4. **확률적 표현**: 참여자 전문성이나 내부정보 여부를 단정하지 않고, 행동 기반 신호와 한계를 함께 표시한다.
5. **점진적 구현**: 처음부터 자체 ML 모델이나 Graph DB를 도입하지 않는다. 검증된 사용 수요와 데이터가 쌓일 때만 고도화한다.

## 단계적 진화

| 단계 | 목적 | 대표 결과 |
|---|---|---|
| 1 | 뉴스·마켓 기반 마련 | 뉴스 수집, 거시 마켓 분류, 확률·거래량 시계열 |
| 2 | 경제 이슈 연결 | `Issue` 모델, 뉴스↔마켓 매칭, 이슈별 근거 조회 |
| 3 | 변화 신호 제공 | 뉴스 버스트, 확률·거래량 급변, 급변 보드 |
| 4 | 참여자 인텔리전스 | 거래 이력, 집중도, 성과·행동 기반 신호 |
| 5 | 고도화 | 임베딩 기반 클러스터링, lead/lag 분석, 그래프 탐색, ML |

## 현재 위치

프로젝트는 1단계의 기반을 구축 중이다.

- 뉴스 조회·수집, PostgreSQL 저장, 캐시, 스케줄러 기반을 갖췄다.
- Polymarket 거시 마켓 분류를 진행 중이며, 이후 확률·거래량 시계열 수집으로 확장한다.
- 뉴스↔마켓 이슈 연결, 급변 신호, 참여자 분석, 프론트엔드 보드는 후속 Slice다.

## 설계 경계

- 경제 이슈 그래프는 처음에는 관계형 데이터 모델로 구현한다. Graph DB는 탐색·관계 질의의 실제 필요가 검증된 뒤 검토한다.
- 실제 외부 API의 데이터 범위·안정성·이용 조건은 기능 착수 전에 Spike로 확인한다.
- 참여자 분석은 관찰 가능한 공개 데이터에 한정하며, 법적·윤리적 표현을 별도 검토한다.

## 갱신 규칙

- 장기 방향, 사용자 가치, 제품 원칙이 바뀌면 이 문서를 갱신한다.
- 실행 범위, API 계약, 데이터 모델, 구현 순서는 각 Slice의 Spec/Plan에서 결정한다.
- 미래에 반복적으로 영향을 주는 설계·프로세스 선택은 ADR로 별도 기록한다.
