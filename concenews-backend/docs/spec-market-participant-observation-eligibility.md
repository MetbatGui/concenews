# Spec: 마켓 참여자 관측 자격

**상태**: 검토 요청
**Slice**: market-participant-observation-eligibility

## 사용자 가치

사용자는 Polymarket의 토큰 변환·정산 흐름으로 생긴 잔고가 상위 참여자나 포지션 변화 신호에 섞여, 일반 참여자의 행동처럼 보이는 일을 피할 수 있다. 시스템은 원본 관측값과 제외 근거를 보존하므로, 신호의 계산 근거를 재검토할 수 있다.

## 범위

### 포함

- 공개 상위 보유 포지션 원본을 수정·삭제하지 않고 계속 저장
- 지갑 주소, 제외 사유, 근거 URL, 등록 시각, 검토 상태를 가진 관측 제외 목록 저장
- 초기 제외 대상 지갑 `0xa5ef39c3d3e10d0b270233af41cac69796b12966` 등록
- 상위 참여자 관측을 읽는 경로에서 활성·검토 완료 제외 지갑을 제거
- 제외된 항목의 주소·사유·근거를 감사용으로 조회 가능하게 보존

### 제외

- Polymarket 소유·운영 계정, 마켓메이커, 일반 참여자의 신원 판정
- 패턴 기반 자동 영구 제외
- 원본 `market_participant_snapshot` 행 삭제·갱신
- 지갑의 손익, 거래 이력, 자금 출처, 전문성 평가
- 사용자 화면 또는 HTTP API 추가

## 용어와 표현 원칙

- **원본 스냅샷**: Data API가 반환한 `MarketParticipantSnapshot`을 가공 없이 저장한 관측값이다.
- **관측 제외 지갑**: 공개 근거상 일반 거래 참여자 신호로 귀속할 수 없어, 상위 참여자 조회와 후속 신호 계산에서 제외하는 지갑이다.
- **제외 후보**: 기계적 패턴으로 발견했지만 사람의 검토가 끝나지 않은 지갑이다. 후보는 관측에서 제외하지 않는다.
- 제외 사유는 소유 주체를 단정하지 않으며, `거래 참여자로 귀속할 수 없음`으로 표현한다.

## Acceptance Criteria

### AC1. 원본 관측값 보존

- 기존 `market_participant_snapshot`의 저장 경로는 제외 목록과 무관하게 모든 Data API 응답을 저장한다.
- 제외 대상 지갑을 포함한 원본 스냅샷 행은 삭제·갱신되지 않는다.
- 동일한 원본 데이터와 다른 제외 정책으로 후속 계산을 다시 실행할 수 있다.

### AC2. 제외 목록 계약

- 제외 목록 항목은 UUID v7 식별자, 정규화한 지갑 주소, 제외 사유, 근거 URL, UTC 등록 시각, 검토 상태, 활성 여부를 가진다.
- 지갑 주소는 소문자 `0x` 접두사의 40자리 16진수여야 한다.
- 같은 지갑의 활성 제외 항목은 하나만 존재한다.
- 초기 대상 지갑은 `검토 완료`·활성 상태로 저장되며 Spike 문서를 근거 URL로 가진다.

### AC3. 관측 자격 적용

- 상위 참여자 관측을 읽는 서비스는 활성·검토 완료 제외 지갑을 결과에서 제거한다.
- 검토 대기 후보와 비활성 제외 항목은 결과에서 제거하지 않는다.
- 제외되지 않은 지갑의 마켓, 결과 인덱스, 원시 보유량, 관측 시각은 변경하지 않는다.
- 제외 목록이 비어 있으면 기존 관측 결과와 동일하다.

### AC4. 테스트 경계

- 지갑 주소 정규화·유효성·활성 중복 규칙은 Unit Test로 검증한다.
- 실제 PostgreSQL에서 제외 목록과 원본 스냅샷을 함께 저장하고, 자격 적용 조회가 원본을 훼손하지 않는지 Integration Test로 검증한다.
- 외부 HTTP 경계는 이 Slice에서 추가하지 않는다. Data API fixture는 기존 참여자 스냅샷 Slice의 것을 유지한다.
- 실제 외부 API는 `check-e2e`에서만 수동 검증하며 `check-branch-green`에는 넣지 않는다.

## 기술 결정

- 원본과 관측 자격 정책의 분리는 [ADR: 마켓 참여자 관측 자격을 원본 스냅샷과 분리](../../docs/decisions/2026-08-15-market-participant-observation-eligibility.md)를 따른다.
- 제외 판단의 Spike 근거는 [Polymarket 시스템성 지갑 관측 자격](../../docs/research/polymarket-system-wallet-eligibility.md)에 기록한다.
- 기존 원본 수집 계약은 [상위 보유 포지션 스냅샷 Spec](./spec-market-participant-snapshot.md)을 유지한다.
